# GrandStay Hotel Management Website

A responsive hotel management website designed for a college project. It includes:

- modern hotel landing page
- room showcase cards
- booking form with validation
- guest reservation table
- hotel dashboard summary cards
- services and contact sections

## Features

- Responsive layout for desktop and mobile devices
- Clean hotel-themed color palette
- Booking form that adds a new reservation to the table
- Room selection shortcut buttons
- Easy-to-edit static front-end project

## Run locally

Open `index.html` directly in a browser, or use a simple local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Project structure

- `index.html` – main page layout
- `style.css` – styling and responsive design
- `script.js` – form validation and booking functionality

## Objective

This project demonstrates a hotel management system interface for educational use, covering front desk reservations and hotel operations.
